# MEMORY.md - 项目长期记忆

_按主题整理仍然成立、会影响未来工作的事实。_

使用方式：
- 每个 `## <主题>` 是一个长期稳定的事实分类。
- 条目简短、陈述式；如果在描述一个决策，最好带上日期。
- 事实变化时**直接修改**对应条目（只保留最新状态）。
- 旧日志汇总归档用 `distill_memory.py`；需要语义整理时手动处理。
