# PROJECT.md - 项目边界

_描述"这个项目是什么 / 不做什么 / 做到什么程度算完"。_
_和 MEMORY.md 不同：MEMORY.md 记录"我们做了什么决定"，这里记录"项目本身是什么"。_

使用方式：
- 每个 `## <分类>` 是一个稳定的项目维度。
- 条目简短、陈述式，写完就**不要常改**——边界变化时**整段改写**，而不是追加。
- 多条事实用 `- ` 列表，单条也可以直接写成段落。
- 内容来自对话中的明确表态（"我们不做 X"、"目标是 Y"），不要靠 agent 猜。

---

## 目标

_项目要解决什么问题 / 服务什么人群。还没有的话先空着，第一次明确时填进来。_

## 非目标

_明确不做的事。重要性比"目标"还高——写下"不做 X"可以避免未来 scope creep。_

## 范围

_当前版本覆盖什么。可以按"功能 / 平台 / 用户类型"等多维度拆开。_

## 约束

_硬性条件：性能、兼容性、依赖、安全合规、不能用的工具等。决策时可以拿来对照。_

## 成功标准

_怎么算"做完了"。可量化最好（响应时间 < 200ms、支持 1k 并发），不能量化也写明"长什么样"。_
